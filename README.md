# dreadabit (web build)

Playable in a browser at **https://jmathes.github.io/dreadabit-web/**

Working title, pre-release. This repo holds only the exported web build of the game
(the Godot wasm runtime, the loader, and the packed game data); the source lives in a
private repo and is published here by its `tools/deploy_web.sh`.

Needs a desktop browser with WebGL 2. The first load fetches about 40 MB.
